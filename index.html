Query Parameters Reference

Customize the player behavior by appending these parameters to the URL:

Parameter Description Value Example
tmdb_id Exact TMDB ID to skip database title lookup (Recommended). 157336 (Interstellar)
title Title string query used as lookup fallback. The+Batman
season TV series season number (omitted or 0 for movies). 1
episode TV series episode number (omitted or 0 for movies). 1
media_type Helps speed up TMDB search queries. movie or tv
